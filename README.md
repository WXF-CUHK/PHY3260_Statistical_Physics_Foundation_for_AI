# PHY3260 Statistical Physics Foundation for AI - Homework 1

## Ising Model Machine Learning Project

This repository contains the implementation of a comprehensive machine learning pipeline for the 2D Ising model, including:

- Temperature prediction using linear regression and neural networks
- Two-stage learning approach for phase classification
- Critical temperature discovery through machine learning

### Files:
- `Q5_Ising_ML_Project.ipynb` - Complete Jupyter notebook implementation

### Key Results:
- Neural network achieves 65.5% improvement over linear regression
- Successfully learns critical temperature with 0.351 error
- Demonstrates phase transition detection with 77% accuracy
